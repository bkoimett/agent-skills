# Canonical startup documents

This reference defines the four canonical project startup documents that project-scaffolder generates and project-standards-audit inspects. All must use uppercase filenames at the project root.

## AGENTS.md

Rules and ground rules for AI agents building the project. Generated by project-scaffolder. Contains conventions, project scope, and definition of done items.

## DESIGN.md

Architecture and UI/design decisions for the project. Generated by project-scaffolder. Contains architecture, UI design, and principles sections.

## WORKFLOW.md

Development, testing, Git, and release workflow. Generated by project-scaffolder. Contains development, verification, Git branching, commit format, and milestone information.

## README.md

Human-facing project overview and setup. Generated by project-scaffolder. Contains project overview, setup, development, testing, and deployment sections.

## Lowercase variants

If lowercase filenames are found (e.g., `agents.md`, `design.md`, `workflow.md`, `readme.md`), inspect their content. Migrate any useful information into the canonical uppercase document. After migration, safely remove or rename the lowercase duplicate. Do not leave lowercase variants coexisting with canonical uppercase documents unless there is a justified reason to maintain both.
